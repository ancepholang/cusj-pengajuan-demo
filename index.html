Panduan Excel

A. Ubah sheet Db menjadi Tabel (satu kali)

Tujuan: anggota baru yang ditempel di bawah Db otomatis ikut terbaca semua rumus VLOOKUP, tanpa mengubah batas baris. Simpan salinan file Excel dulu sebelum mulai.

  1. Di sheet Db, blok A4:AW4 (baris angka 1, 2, 3...), tekan Ctrl+X, klik A1, tekan Ctrl+V. Baris angka itu hanya bantuan dan tidak dipakai rumus lain.
  2. Klik kanan nomor baris 4 (yang sekarang kosong), pilih Delete. Header (baris 3) sekarang langsung bersambung dengan data.
  3. Klik satu sel di data, tekan Ctrl+T. Pastikan rentang A3 sampai kolom AQ baris terakhir, centang My table has headers, OK. Header yang kosong atau kembar akan diberi nama otomatis, itu aman.
  4. Di tab Table Design, ubah Table Name menjadi tblDb.
  5. Tekan Ctrl+H. Klik Options, isi Within: Workbook dan Look in: Formulas. Ganti satu per satu (Replace All) teks berikut dengan tblDb:
    Cari teksJumlah rumus
    Db!$A$4:$AN$3116138
    Db!$A$4:$AQ$4524488
    Db!$A$4:$AN$4524459
    Db!$A$4:$AN$30054
    Db!$A$4:$AN$18944
    Db!$A$4:$AQ$31163
    Angka di atas sudah memperhitungkan penghapusan baris 4 pada langkah 2. Setelah itu rumus seperti =VLOOKUP($E$20,tblDb,12,0) tetap bekerja dengan nomor kolom yang sama. Cek dengan Ctrl+F, cari Db!$A$ pada Formulas. Jika masih ada sisa dengan angka lain, ganti dengan cara yang sama.

B. Masukkan anggota baru ke Db

  1. Di menu Anggota Baru, isi No. BA, tanggal jadi anggota, Box, dan No untuk anggota yang sudah diverifikasi.
  2. Klik Salin baris untuk sheet Db.
  3. Di Excel, klik sel A pada baris kosong tepat di bawah data terakhir Db, tekan Ctrl+V. Tabel melebar sendiri dan kolom TTL serta Usia terisi otomatis.
  4. Buat ulang daftar anggota di menu Daftar Anggota dan berikan ke staf agar anggota baru bisa dicari.

C. Bawa pengajuan ke form Excel (cetak dari Excel Master)

Staf hanya mengisi data wawancara. Admin memilih satu pengajuan, lalu semua form (Panduan Pengajuan, Formulir Permohonan Kredit, Laporan Aset dan Penghasilan, Jadwal Angsuran) terisi sendiri dan dicetak dari Excel seperti biasa.

  1. Buat sheet baru bernama Rekap Pengajuan (tanpa Tabel). Di menu Impor Pengajuan klik Salin tabel, tempel di A1 termasuk judul kolom. Setiap ada pengajuan baru, tempel ulang dari A1.
  2. Unduh makro:
  3. Di Excel tekan Alt+F11 > File > Import File > pilih file .bas. Simpan workbook sebagai .xlsm (salinan, jangan menimpa file asli).
  4. Tekan Alt+F8, jalankan PasangRumusRekap satu kali. Makro mengganti sel isian (nama, jumlah, jangka, bunga, tabungan, modal, aset, hutang, penghasilan, pengeluaran, jaminan) dengan rumus yang membaca sheet Rekap Pengajuan. Untuk sel jaminan, jika staf tidak mengisi, rumus lama (ambil dari Db) tetap dipakai.
  5. Pilih ID pengajuan di sel AA1 sheet Panduan Pengajuan (daftar pilihan otomatis). Semua form langsung terisi, lalu cetak.
  6. Opsional: jalankan PerbaikiRumusBermasalah untuk memperbaiki rumus yang salah di file asli (Penghasilan Bersih memakai pengeluaran baris terakhir saja, dan nomor BA jaminan simpanan tertukar).
Yang tetap manual: kode pinjaman, bunga F18, dan sel lain yang tidak diisi staf. Makro belum bisa diuji di Excel oleh pembuatnya: uji dulu pada salinan file.

D. Kotak surat write-only di Windows

  1. Buat folder, misalnya D:\KotakSurat. Klik kanan > Properties > Sharing > Advanced Sharing > centang Share this folder, lalu Permissions dan beri akun staf Change.
  2. Tab Security > Advanced > Add. Pilih akun atau grup staf. Pilih This folder and subfolders, centang hanya Create files / write data dan Create folders / append data. Hapus izin Read, List, dan Delete untuk staf. Akun admin tetap Full control.
  3. Di PC staf, buka folder lewat jaringan (\\NAMA-PC-ADMIN\KotakSurat) dan petakan sebagai drive jika perlu. Lalu di aplikasi (masuk sebagai admin), menu Pengaturan, tekan Pilih folder kotak surat dan Tes tulis ke folder.
  4. Jika browser menolak memilih folder write-only, aplikasi staf otomatis mengunduh file pengajuan. Staf lalu menaruh file itu ke folder tersebut lewat File Explorer (menyalin file ke folder write-only tetap bisa).
